# 分享只读页文档大纲

此文件与 `2026-11-04-share-outline.md` 内容相同，作为中文变更清单入口。

## 问题与目标

Issue #775 要求 Web 分享只读页面提供与编辑器一致的文档大纲：按标题层级导航，点击标题跳转，并保留“折叠全部标题”和“展开全部标题”。普通 `/share/:token` 页面当前没有大纲；公开笔记本站点已有基础大纲但缺少批量折叠操作。

## 允许的变更清单

- 为普通分享页和公开笔记站点复用同一套只读文档大纲：从渲染后的 H1–H4 标题生成层级树，点击标题平滑定位并高亮当前章节。
- 在桌面端显示右侧大纲，在移动端提供抽屉入口；没有标题时不渲染大纲入口。
- 增加“折叠全部标题”和“展开全部标题”，仅改变大纲树的可见层级，不折叠正文内容；只读页面状态不写入笔记或服务端。
- 保持现有分享正文、锚点跳转、图片预览、站点搜索和双向链接预览行为不变。
- 增加能覆盖标题树与批量折叠行为的最小自动化校验，并运行受影响的 Web 类型检查/测试。

## 保持不变的边界

- 不修改分享 API、Token、鉴权、密码解锁和正文数据结构。
- 不改变编辑器 `EditorOutline` 的编辑态持久化和交互。
- 不扩展到 H4 以外的标题层级；沿用公开笔记站点已有 H1–H4 导航契约。
- 不提交、推送、合并或部署；当前任务只交付独立 worktree 中的实现和验证结果。

## 完成核对

- 已实现共享的只读大纲，并接入普通分享页和公开笔记本站点。
- 已增加标题层级与可折叠父节点的纯函数测试，2 项均通过。
- 变更 TypeScript 文件已通过 `oxlint`。
- 完整类型检查和 Web 构建受当前 checkout 依赖不完整及既有项目错误阻塞；新增大纲文件未报告专属错误。
